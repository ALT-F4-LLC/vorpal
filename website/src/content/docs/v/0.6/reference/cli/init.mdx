## Language prompt {#prompt}

`init` asks which SDK the config program uses, then writes these files:

- **Go:** `cmd/<name>/main.go`, `cmd/vorpal/main.go`, `go.mod`, `go.sum`, `Vorpal.toml`. The template folder `cmd/example/` is renamed to `cmd/<name>/`.
- **Python:** `pyproject.toml`, `uv.lock`, `src/main.py`, `src/vorpal.py`, `Vorpal.toml`, `.gitignore`.
- **Rust:** `Cargo.toml`, `Cargo.lock`, `src/main.rs`, `src/vorpal.rs`, `Vorpal.toml`, `.gitignore`.
- **TypeScript:** `src/vorpal.ts`, `src/main.ts`, `package.json`, `tsconfig.json`, `Vorpal.toml`, `.gitignore`, `bun.lock`.

It writes no `Vorpal.lock`: run [`vorpal prepare`](/reference/cli/prepare/) before the first build.

## Examples {#examples}

```bash prompt
# Create a project in the current folder
vorpal init my-project
# Create a project in another folder
vorpal init my-project --path /path/to/project
```
