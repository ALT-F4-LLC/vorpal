## Synopsis {#synopsis}

<CliSynopsis command="run" />

`run` finds the alias's digest (in the local store, then the registry), pulls the artifact if it isn't in the local store, and replaces itself with the program from the artifact's `bin/` folder.

## Examples {#examples}

```bash prompt
# Run an artifact's program
vorpal run my-tool
# Run another program from the same artifact
vorpal run my-tools --bin specific-tool
# Pass arguments to the program
vorpal run my-tool -- --verbose --output /tmp/out
# Run from a namespace, at a tag
vorpal run my-namespace/my-tool:v1.0
```
