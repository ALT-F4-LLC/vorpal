## Install the SDK {#install}

```bash prompt
bun add @altf4llc/vorpal-sdk
```

Or with npm: `npm install @altf4llc/vorpal-sdk`, or with Yarn: `yarn add @altf4llc/vorpal-sdk`.

## Project layout {#layout}

This is what `vorpal init` writes for TypeScript, plus the `Vorpal.lock` that [`vorpal prepare`](/reference/cli/prepare/) adds.

```text title="Project layout"
hello-world/
├── .gitignore
├── Vorpal.lock        # written by vorpal prepare; commit it
├── Vorpal.toml        # language = "typescript", includes
├── bun.lock
├── package.json       # @altf4llc/vorpal-sdk 0.6.0
├── tsconfig.json
└── src/
    ├── vorpal.ts      # the config program
    └── main.ts        # your program
```

```toml title="Vorpal.toml"
language = "typescript"

[source]
includes = [
    "bun.lock",
    "package.json",
    "src/vorpal.ts",
    "tsconfig.json"
]
```

`language` tells Vorpal to use the TypeScript SDK. `[source]` lists the files the config program needs. Every key is in the [configuration reference](/reference/configuration/).

## TypeScript facts {#facts}

- The config program and TypeScript artifacts are built with a pinned Bun runtime.
- The development environment builder adds Bun; add other tools, such as `protoc`, with `withArtifacts`.
