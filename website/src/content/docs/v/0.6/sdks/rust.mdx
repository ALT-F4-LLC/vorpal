## Install the SDK {#install}

Add the SDK to your project's `Cargo.toml`, with a second binary named `vorpal` for the config program:

```toml title="Cargo.toml"
[package]
edition = "2021"
name = "hello-world"
version = "0.1.0"

[[bin]]
name = "hello-world"
path = "src/main.rs"

[[bin]]
name = "vorpal"
path = "src/vorpal.rs"

[dependencies]
anyhow = "1"
tokio = { features = ["rt-multi-thread"], version = "1" }
vorpal-sdk = { version = "0.6.0" }
```

## Project layout {#layout}

This is what `vorpal init` writes for Rust, plus the `Vorpal.lock` that [`vorpal prepare`](/reference/cli/prepare/) adds.

```text title="Project layout"
hello-world/
├── .gitignore
├── Vorpal.lock        # written by vorpal prepare; commit it
├── Vorpal.toml        # language = "rust", includes
├── Cargo.lock
├── Cargo.toml         # bins hello-world and vorpal, vorpal-sdk 0.6.0
└── src/
    ├── vorpal.rs      # the config program
    └── main.rs        # your program
```

```toml title="Vorpal.toml"
language = "rust"

[source]
includes = [
    "Cargo.lock",
    "Cargo.toml",
    "src/vorpal.rs"
]
```

`language` tells Vorpal to use the Rust SDK. `[source]` lists the files the config program needs. Every key is in the [configuration reference](/reference/configuration/).

## Rust facts {#facts}

- The development environment builder adds the Rust toolchain (`rustc`, `cargo`, `clippy`, `rustfmt`, `rust-src`, `rust-analyzer`) and `protoc`. `without_protoc()` leaves `protoc` out.
