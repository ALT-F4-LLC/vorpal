## Install the SDK {#install}

```bash prompt
go get github.com/ALT-F4-LLC/vorpal/sdk/go
```

## Project layout {#layout}

This is what `vorpal init` writes for Go, plus the `Vorpal.lock` that [`vorpal prepare`](/reference/cli/prepare/) adds.

```text title="Project layout"
hello-world/
├── Vorpal.lock        # written by vorpal prepare; commit it
├── Vorpal.toml        # language = "go", includes, directory
├── go.mod
├── go.sum
└── cmd/
    ├── vorpal/
    │   └── main.go    # the config program
    └── hello-world/
        └── main.go    # your program
```

```toml title="Vorpal.toml"
language = "go"

[source]
includes = [
    "cmd/vorpal",
    "go.mod",
    "go.sum",
    "internal/vorpal"
]

[source.go]
directory = "cmd/vorpal"
```

`language` tells Vorpal to use the Go SDK. `includes` lists only the files the config program needs; keeping it short keeps more builds cached. `[source.go]` sets the folder of the config program's `main` package. The layout follows the <a href="https://github.com/golang-standards/project-layout">Standard Go Project Layout</a>. Every key is in the [configuration reference](/reference/configuration/).

## Go facts {#facts}

- The development environment builder adds Go, `goimports`, `gopls`, `staticcheck` and `protoc`. `WithoutProtoc()` leaves `protoc` out.
