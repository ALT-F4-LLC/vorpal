## Install the SDK {#install}

```bash prompt
uv add vorpal-sdk
```

Or with pip: `pip install vorpal-sdk`. The package needs Python 3.14 (`>=3.14,<3.15`).

## Project layout {#layout}

This is what `vorpal init` writes for Python, plus the `Vorpal.lock` that [`vorpal prepare`](/reference/cli/prepare/) adds.

```text title="Project layout"
hello-world/
├── .gitignore
├── Vorpal.lock        # written by vorpal prepare; commit it
├── Vorpal.toml        # language = "python", includes, entrypoint
├── pyproject.toml     # requires-python = ">=3.14,<3.15", vorpal-sdk>=0.6.0
├── uv.lock
└── src/
    ├── vorpal.py      # the config program
    └── main.py        # your program
```

```toml title="Vorpal.toml"
language = "python"

[source]
includes = [
    "pyproject.toml",
    "uv.lock",
    "src",
]

[source.python]
directory = "."
entrypoint = "src/vorpal.py"
```

`language` tells Vorpal to use the Python SDK. `includes` lists only the files the config program needs; keeping it short keeps more builds cached. `[source.python]` sets the folder and the config program's entrypoint. Every key is in the [configuration reference](/reference/configuration/).

## Python facts {#facts}

- Python packages are installed with `uv sync --frozen`, so they are pinned by `uv.lock`.
- The development environment builder adds the built-in `cpython` and `uv` artifacts, and sets `UV_PYTHON_DOWNLOADS=never` so the shell never fetches its own interpreter.
- The built-in interpreter is CPython 3.14.7. <span class="vp-pln">Planned: more CPython versions · <b>ENG-366</b></span>
- `OciImage` in the Python SDK needs `crane` and `rsync` passed in with `with_crane` and `with_rsync`. <span class="vp-pln">Planned · <b>ENG-371</b></span>
