## Environment variables {#environment-variables}

### `VORPAL_SOCKET_PATH` {#env-vorpal-socket-path}

Changes the default socket path, `/var/lib/vorpal/vorpal.sock`. Every `--agent`, `--registry` and `--worker` default then points to `unix://<path>`, and `vorpal system services start` listens there when it has no `--port`.

### `VORPAL_ISSUER_CLIENT_SECRET_FILE` {#env-vorpal-issuer-client-secret-file}

The same as [`--issuer-client-secret-file`](/reference/cli/system/services/#flag-issuer-client-secret-file) on `vorpal system services start`.

### `VORPAL_ISSUER_SERVICE_CLIENT_IDS` {#env-vorpal-issuer-service-client-ids}

The same as [`--issuer-service-client-ids`](/reference/cli/system/services/#flag-issuer-service-client-ids) on `vorpal system services start`.

### `VORPAL_USER_CONFIG_DIR` {#env-vorpal-user-config-dir}

Changes the folder of your settings file, `~/.vorpal/settings.json`. See [Configuration](/reference/configuration/#settings-json).

## Exit codes {#exit-codes}

- `0`: success.
- `1`: an error, such as a failed build, a missing artifact or a configuration error.
- `2`: a usage error, such as an unknown flag.
